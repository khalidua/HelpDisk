 26///      before the object exists. There is no such thing as an invalid Ticket -

 29///   3. BEHAVIOUR METHODS THAT RETURN Result. Assign() refuses to work on a
 30///      closed ticket and says why. The refusal is a value, not an exception.
 31///

 40/// never in one place, so it was never really a rule.
